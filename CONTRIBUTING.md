# Como contribuir

1. Associe sempre pelo código IBGE de sete dígitos; nome e UF são apenas fallback controlado.
2. Registre página de origem, URL original, autor, crédito, licença, URL da licença, data e hashes.
3. Não inclua imagem sem procedência ou aplique MIT a assets.
4. Execute `npm test`, `npm run typecheck` e `npm run lint`.
5. Envie cada candidato para revisão; nunca aprove um lote automaticamente.

Não sobrescreva um asset aprovado. Uma nova versão deve ser marcada `desatualizado`, comparada e aprovada de forma explícita.
