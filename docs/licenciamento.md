# Licenciamento dos assets

O código é MIT; as imagens não são. Para cada arquivo deve-se consultar a página no Commons e preservar autor, crédito, licença, URL, condições, origem e data. Um link isolado pode não satisfazer atribuição, ShareAlike ou indicação de mudanças.

Modificações são registradas. Derivados de CC BY-SA preservam a licença aplicável e a atribuição. Em domínio público, o catálogo mantém a declaração, o motivo/template informado, a página e a data. Licença obscura produz `licenca_pendente`: guarda-se o candidato, não se publica original nem derivado aprovado.

O projeto não concede direitos além dos existentes na fonte. Este documento descreve a política técnica do projeto e não é parecer jurídico.
